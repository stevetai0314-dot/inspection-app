走動路線與前日異常

graph TD A[ZONES 定義\n每個 Zone 有 machines 陣列] --> B[陣列順序 = 走動路線\n不做排序] B --> C[工人照畫面順序\n逐台巡視] D[JSONP GET 前日異常] --> E[異常機台 ID 清單] E --> F{渲染機台 chip 時} F -- 在異常清單內 --> G[加上 ⚠ 樣式] F -- 正常 --> H[一般樣式] G & H --> I[工人優先注意 ⚠ 機台] style G fill:#fce8e8,stroke:#d32f2f style B fill:#fce8b2,stroke:#e65100

重點說明

  • 核心設計原則「走過去沒問題，就不登記」— 只有例外才需要記錄，平均每筆約 30 秒
  • Set 追蹤 用 JavaScript Set 管理已選擇的問題類型，toggle 開/關，送出時只帶選中的欄位
  • 前日異常 用 JSONP 方式繞過 CORS 限制從 GAS GET 資料，在機台上標示 ⚠ 提醒工人特別注意
  • 走動路線用 ZONES 陣列定義，陣列順序就是實際路線，不是機台號碼順序
  • 離線佇列用 timestamp 作為 _id 去重，上線後自動批次補傳
